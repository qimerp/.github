# qimerp/.github

Special organization repository for [qimerp](https://github.com/qimerp).

| Path | Purpose |
| --- | --- |
| `profile/README.md` | Public organization profile (shown on https://github.com/qimerp) |
| `.github/CODEOWNERS` | Default owners for *this* repository only |
| `.github/SECURITY.md` | Org-default security policy (fallback for repos without their own) |
| `.github/CONTRIBUTING.md` | Org-default contribution guide |
| `.github/SUPPORT.md` | Org-default support / escalation |
| `.github/pull_request_template.md` | Org-default PR template |

Product repositories should still carry their own `CODEOWNERS` (team handles such as `@qimerp/backend`). Org-default community health files apply only when a repository does not define its own copy.
